# Smart Library Management System using Java

## Project Overview

The Smart Library Management System is a console-based Java application designed to manage books, students, and book issue/return operations in a library.

The project demonstrates important Java programming concepts such as Object-Oriented Programming, collections, file handling, exception handling, and command-line execution.

## Features

- Add new books
- View all books
- Search books by Book ID
- Search books by title keyword
- Register students
- View registered students
- Issue books to students
- Return books
- Maximum limit of 3 books per student
- Duplicate Book ID prevention
- Duplicate Student ID prevention
- Input validation
- Exception handling for invalid menu input
- Library statistics
- File-based data storage
- Data loading when the application starts
- Data saving when the application exits
